SECTION A3 — FEATURES OVERVIEW

Architecture des cartes

La section Features est composée de 5 Feature Cards.

La disposition doit respecter une grille asymétrique :

<div class="flex gap-[20px] flex-wrap content-center items-center justify-center">
  <div class="grow w-[40%] h-[175px]">Feature 1</div>
  <div class="grow w-[40%] h-[175px]">Feature 2</div>
  <div class="grow w-[20%] h-[175px]">Feature 3</div>
  <div class="grow w-[20%] h-[175px]">Feature 4</div>
  <div class="grow w-[20%] h-[175px]">Feature 5</div>
</div>

Les deux premières cartes sont plus larges.

Les trois cartes inférieures sont plus compactes.

L'ensemble doit conserver un équilibre visuel parfait.

---

Analyse obligatoire des cartes

Ne pas considérer ces cartes comme de simples blocs contenant une image.

Chaque Feature Card est composée de plusieurs couches :

- structure principale ;
- bordure lumineuse ;
- arrière-plan ;
- contenu textuel ;
- composant visuel interactif.

---

Composants visuels internes

Les illustrations présentes dans les cartes ne sont pas des images statiques.

Elles doivent être développées sous forme de composants React indépendants.

Ces composants doivent être :

- entièrement codés ;
- réutilisables ;
- responsives ;
- intégrés au Design System ;
- compatibles avec les animations.

---

SVG avancés

Des SVG spéciaux seront fournis.

Ces SVG ne doivent pas être traités comme de simples illustrations.

Ils servent de conteneurs visuels avancés capables d'accueillir :

- composants React ;
- badges ;
- avatars ;
- graphiques ;
- boutons ;
- indicateurs ;
- éléments dynamiques ;
- animations.

Les SVG doivent être considérés comme une partie active de l'interface.

---

Animations

Les composants visuels internes doivent être légèrement animés.

Utiliser principalement :

- Framer Motion ;
- GSAP lorsque nécessaire.

Exemples :

Carte Notifications

- apparition progressive des notifications ;
- légère translation verticale ;
- pulsation discrète des indicateurs.

Carte Collaboration

- animation subtile des messages ;
- effet de présence en temps réel ;
- micro-interactions.

Carte Growth

- animation de la courbe ;
- remplissage progressif du graphique ;
- animation des statistiques.

Carte Metrics

- animation du compteur ;
- rotation légère de l'indicateur ;
- variation subtile de luminosité.

Carte Analytics

- animation des barres ;
- apparition progressive des données ;
- micro-mouvements continus.
